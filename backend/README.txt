BACKEND — NÃO PUBLIQUE ESTA PASTA NO GITHUB PAGES

1. Crie uma planilha Google Sheets.
2. Extensões > Apps Script.
3. Cole o conteúdo de Code.gs no editor.
4. Troque ADMIN_KEY por uma senha/chave privada.
5. Implante como Aplicativo da Web, executando como você e permitindo acesso público/anônimo.
6. Copie a URL /exec para docs/config.js.

O GitHub Pages deve publicar SOMENTE a pasta /docs.
